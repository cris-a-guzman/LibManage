# PoC - Open Library API

Esta carpeta contiene una prueba de concepto para evaluar la integración de la API de Open Library en LibManage.

## Objetivo

Investigar cómo utilizar la API de Open Library para realizar búsquedas de libros y obtener información que pueda utilizarse posteriormente en la aplicación.

## Alcance

En esta PoC se experimenta con:

* Búsqueda de libros mediante la API.
* Consulta de información como título, autor y año de publicación.
* Procesamiento de la respuesta JSON.
* Evaluación de cómo integrar los resultados con LibManage.

## Estado

Esta funcionalidad es **experimental** y no forma parte de la implementación actual de LibManage.

El código de esta carpeta se utiliza únicamente para investigar y validar la viabilidad de una futura integración con Open Library.

## API utilizada

Open Library Search API:
https://openlibrary.org/dev/docs/api/search
